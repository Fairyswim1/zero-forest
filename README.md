# 넘버 블룸 · 플레이 샘플 v0.2

이웃한 숫자 돌을 2~4개 이어 **지금 목표 수**를 만들면 지웁니다. 화면 위에 보이는 목표를 왼쪽부터 차례로 모두 만들면 성공합니다. 돌이 남아도 됩니다.

## 생각할 것은 다음 한 수
- 1단계: 0 → +3. 같은 조작으로 목표가 바뀌는 것을 익힙니다.
- 2단계: +3 → −2. 두 돌로 +3을 만드는 선택도, 어느 돌을 쓰는지에 따라 다음 목표가 막힙니다.
- 3단계: 세 수를 이용해 목표를 구성합니다.
- 4~6단계: 세 목표의 재료와 낙하 후 이웃을 함께 남깁니다.

규칙은 단계마다 같고, 돌이 지워지면 위의 돌이 내려옵니다. 한 수 전은 목표와 돌을 함께 되돌립니다. 시간 제한·별도 지우기 횟수는 없습니다. 자동 정답 미리보기는 없으며 제출 후 합을 알려줍니다.

실제 학생의 이해도·재미는 아직 검증하지 않았습니다. 독립 풀이 탐색과 6개 단계의 브라우저 플레이를 검증했습니다. 반례와 해결 경로는 design.json, 검증은 tests와 evidence에 있습니다.

## 실행과 배포
`npm start` 후 http://127.0.0.1:4174 를 엽니다. `PORT`로 포트를 바꿀 수 있습니다.
`npm test`는 게임의 목표 순서·자원 선택·독립 풀이·학습 기록 검증을 실행합니다.
`npm run build`는 dist에 독립 배포본을 만듭니다. Vercel에서 이 저장소를 Import하면 vercel.json을 사용합니다. 현재는 로컬 검토용 샘플이며 배포 URL은 확인되지 않았습니다.

## 학습 확인
9수01-05 중 정수 덧셈과 목표 합 구성만 확인합니다. 다른 사칙계산·유리수·실생활 유용성은 미확인입니다. 게임 성공은 이수 판정이 아닙니다. 새로운 수의 첫 응답·오답·도움·재시도와 학생 설명, 교사 검토, JSON 내보내기를 별도 화면에서 제공합니다.

새 규칙의 진행과 확인 과제는 v0.2 전용 저장 키를 사용하며, 이전 버전 기록은 삭제하지 않습니다. 모든 기록은 브라우저에만 저장됩니다.

숫자 돌·버튼·배경·정령은 내장 이미지 생성으로 만든 기존 에셋을 사용합니다. 생성 프롬프트는 assets/prompts.json, 교육과정 범위는 assessment.json, 교과서 근거는 sources.json에 있습니다. 원본 PDF와 추출문은 포함하지 않습니다.

## v0.2.1 화면 확대
PC에서는 화면 높이에 맞춰 판을 넓히고 목표와 조작을 오른쪽에 배치합니다. 1281×720에서 판 너비 약 720px, 1920×1080에서 약 1200px입니다. 390px 모바일에서는 가로 여백을 줄이고 목표→게임판→조작 순으로 표시합니다. 게임과 평가 규칙은 v0.2.0과 같습니다.

## v0.3 넘버 블룸
기존 URL과 저장소는 유지합니다. 단계별 판 4×3→5×4→6×5, 돌 4·8·14·20·24·30개, 목표 2→5개. 돌 크기는 PC에서도 약 100px 이하로 제한합니다. 이전 단계 배치와 섞이지 않도록 진행 저장은 v3을 사용하며 독립 학습 기록은 유지합니다. 효과음 켜기/끄기와 실제 출력 신호 확인 버튼을 제공합니다.

## 처음 실행하는 화면 집중 튜토리얼
처음 방문하면 실제 화면의 목표와 조작을 하나씩 강조합니다. 첫 성공까지 직접 조작해야 다음 단계로 넘어갑니다. 건너뛰기·연습 다시·상단 처음 안내를 제공합니다. 튜토리얼은 별도 메모리 저장소에서 진행하므로 기존 단계·점수·독립 학습 기록을 덮어쓰지 않습니다. 완료 또는 건너뛰기만 게임별로 기기에 저장합니다. 저장이 제한되어도 현재 URL의 tutorial=off로 반복 진입을 방지합니다. 키보드 Tab/Shift+Tab과 Escape, 모바일 화면을 지원합니다.

## v0.4 넘버 블룸 — 수로 피우는 숲
사용자가 선택한 제목 적용. 수학 아틀리에는 작은 홈 링크로, 게임 제목은 큰 제목으로 표시합니다. 신규 image_gen 원형 등불 에셋으로 정원 선택을 구성했습니다. 넓은 화면은 지도·퍼즐·목표의 3영역을 화면 높이 가운데 배치하고 타일 크기 상한을 유지합니다. 18라운드·꽃 수집 확장은 design.json의 기획 제안이며 현재 플레이 가능한 정원은 기존 6개입니다. 저장 키와 스테이지·학습 기록은 유지합니다.
