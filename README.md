# 넘버 블룸 — 수로 피우는 숲

이웃한 돌 2~4개를 이어 지금 목표를 만들고, 왼쪽부터 목표를 모두 완성하는 18라운드 퍼즐입니다. 돌을 지우면 위의 돌이 내려옵니다. 시간 제한과 추가 화폐 없이 같은 규칙을 유지합니다.

## 세 정원과 꽃
- 씨앗의 숲 1~6: 목표 합 구성과 다음 돌 남기기 → 햇살꽃.
- 잔빛의 정원 7~12: 같은 합의 여러 조합 중 미래 목표의 재료 보존 → 이슬방울꽃.
- 만개하는 숲 13~18: 같은 숫자 조합도 위치가 다르면 결과가 달라지는 낙하 퍼즐 → 별빛꽃.

각 정원의 여섯 라운드를 모두 마치면 꽃을 얻습니다. 세 꽃을 모으면 만개한 숲 엔딩을 열고 꽃 모음에서 다시 볼 수 있습니다. 순서와 재도전은 자유로우며 이미 얻은 꽃은 사라지지 않습니다. 기존 v3 진행 기록을 그대로 이어 사용합니다.

## 실행·검증
- npm start (기본 4174, PORT 변경 가능)
- npm test: 독립 풀이 탐색, 모든 라운드, 미래 목표 실패 반례, 낙하 위치 선택, 저장·꽃 획득 조건, 성취기준 기록 검증.
- npm run build: 독립 Vercel 빌드. 저장소/주소는 zero-forest 그대로 유지합니다.

## 접근성과 학습 확인
처음 실행하면 화면을 집중시키는 실제 조작 튜토리얼이 나옵니다. 기존 진행과 분리된 연습이며 다시 보기·건너뛰기가 가능합니다. 키보드와 390px 화면, 움직임 줄이기를 지원합니다.

9수01-05 중 정수 덧셈과 목표 합 구성만 확인합니다. 꽃·승리는 공식 이수 판정이 아닙니다. 새로운 수의 첫 응답·오답·도움·재시도와 학생 설명, 교사 검토, 내보내기는 별도 학습 확인 화면에 있습니다. 실제 학생의 재미·학습 효과는 아직 검증하지 않았습니다.

배경·숫자 돌·버튼·정령·라운드 등불·꽃 3종 아틀라스·개화 엔딩 그림은 내장 image_gen으로 생성했습니다. 프롬프트는 assets/prompts.json, 새 에셋 원문은 assets/expansion-prompts.json에 있습니다. 교과서 PDF와 추출문은 배포본에 포함하지 않습니다.
