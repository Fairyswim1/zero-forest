# 제로 숲 · 플레이 샘플

이웃한 숫자 돌을 2~4개 이어 합이 0이면 지웁니다. 주어진 횟수 안에 판을 모두 비우면 성공합니다. 지운 자리에 위의 돌이 내려옵니다.

## 이번에 확인할 방향
- 새 규칙이나 별도 자원을 계속 추가하지 않고, 같은 조작에서 조합·남길 돌·낙하 순서를 고민하게 합니다.
- 1~2단계는 조작과 세 수 연결을 익히고, 3~4단계는 긴 연결과 남은 배치, 5~6단계는 낙하 이후의 수를 생각합니다.
- 시간제한은 없고 한 수 전으로 자유롭게 되돌릴 수 있습니다. 숫자 돌·버튼·배경·정령은 내장 이미지 생성으로 제작했습니다.
- 아직 실제 중학생에게 재미나 첫 행동 이해도를 검증한 것은 아닙니다. 이 버전은 게임 방향을 논의하기 위한 샘플입니다.

## 실행
Node.js 환경에서 `npm start` 후 http://127.0.0.1:4174 를 엽니다. `PORT`로 포트를 변경할 수 있습니다.

`npm test`: 수학, 독립 풀이 탐색, 잘못된 선택, 실패·복구, 학습 기록 검증.
`npm run build`: 독립 배포본을 dist에 생성합니다.

Vercel에서 이 저장소를 Import하면 vercel.json을 사용합니다. 빌드 명령 npm run build, 출력 dist, 프레임워크 Other. 현재 배포 URL이 확인되지 않은 로컬 검토용 샘플입니다.

## 학습 확인 범위
9수01-05 중 정수 덧셈과 합 0의 구성만 다룹니다. 다른 사칙계산과 유리수, 실생활 유용성은 미확인입니다. 게임 성공을 이수 판정으로 사용하지 않습니다. 별도의 새 수 확인 과제에 첫 응답·오답·도움·재시도를 기록하고 학생 설명·교사 검토·JSON 내보내기를 제공합니다. 모든 기록은 해당 브라우저에만 저장합니다.

기획과 근거는 design.json, sources.json, assessment.json에 있습니다. 생성 이미지 원문 프롬프트와 역할은 assets/prompts.json에 있습니다. 원본 교과서와 추출문은 포함하지 않았습니다.
